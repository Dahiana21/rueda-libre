Roles en el sitio Rueda Libre
HTML: Es quien nos da la estructura de nuestra página web ayudandonos a definir cosas
como por ejemplo, el titulo, el contenido, imagenes, etc...
CSS: Es quien nos aporta toda la parte estetica define los colores, las tipografías, el espaciado y la disposición de los elementos 
creados con HTML para que el sitio sea atractivo visualmente, por ejemplo el color del texto, el color de fondo, etc..
JavaScript: ermite que el sitio responda a las acciones del usuario en tiempo real, 
modifique el contenido dinámicamente sin recargar la página y maneje la lógica del negocio, como por ejemplo al dar clic en 
un boton si haga la función.

ACTIVIDAD EL FORMULARIO DE Reservas

En la página de Reservas de Rueda Libre se creó un formulario HTML utilizando el método POST. 
Se organizaron los campos en tres grupos con las etiquetas fieldset y legend: "Tus datos", "Tu alquiler" y "Confirmación".

1. Correo electrónico (input type="email"): Se eligió porque permite que el navegador verifique que el dato ingresado tenga un formato 
de correo electrónico válido.

2. Tipo de bicicleta (select): Se utilizó una lista desplegable porque el cliente debe elegir entre opciones definidas: urbana, montaña o eléctrica. 
Esto evita que escriba opciones diferentes a las disponibles.

3. Aceptación de políticas (input type="checkbox"): Se eligió una casilla de verificación porque el usuario debe confirmar su aceptación 
de las políticas de alquiler antes de enviar el formulario.

También se utilizó la etiqueta label vinculada con cada campo mediante los atributos for e id, y el atributo name 
para identificar cada dato durante el envío. Finalmente, se agregó un botón de tipo submit para enviar la información.

Reservas sin errore, validación y teclado
Se usaron validaciones nativas para garantizar que los usuarios ingresen correctamente sus datos
Se utilizo el atributo required para identificar que campos son obligatorios

de politicas
